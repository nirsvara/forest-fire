# Bab 8 — Kebijakan Karhutla, Rezim & Dampak

Dashboard visualisasi bahan riset Bab 8 untuk laporan *Indonesia's Fire: A Nation Under Siege By Oligarchy* (Trend Asia).

Mencakup:
- Timeline regulasi karhutla pemerintah 2013–2026 (era SBY / Jokowi / Prabowo-Gibran)
- Status kebijakan zero-fire 30 grup usaha pemegang PBPH (kehutanan) & IUP (pertambangan)
- Skala dampak karhutla: area terbakar, emisi karbon, dampak kesehatan 2026

**Live:** https://nirsvara.github.io/forest-fire/

## Sumber

Seluruh data bersumber dari situs resmi pemerintah (peraturan.go.id, sipongi.gakkum.kehutanan.go.id, bnpb.go.id, kemkes.go.id, setkab.go.id) dan situs resmi korporasi. Detail lengkap dengan kutipan sumber & nomor halaman dokumen PDF tersedia di file Excel/Word pendamping riset ini (tidak disertakan di repo ini).

## Menjalankan lokal

Buka `index.html` langsung di browser, atau jalankan server statis sederhana:

```bash
python -m http.server 8000
```
