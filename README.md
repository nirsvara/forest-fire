# Kebijakan Karhutla Indonesia

Halaman data mengenai kebijakan kebakaran hutan dan lahan (karhutla) di Indonesia.

Mencakup:
- Timeline regulasi karhutla pemerintah 2013 sampai 2026
- Status kebijakan pencegahan karhutla di 43 grup usaha pada sektor kehutanan (PBPH), pertambangan (IUP), dan perkebunan sawit
- Skala dampak karhutla: area terbakar, emisi karbon, dampak kesehatan 2026

**Live:** https://nirsvara.github.io/forest-fire/

## Sumber

Data bersumber dari situs resmi pemerintah (peraturan.go.id, sipongi.gakkum.kehutanan.go.id, bnpb.go.id, kemkes.go.id, setkab.go.id) dan situs resmi masing-masing perusahaan.

## Menjalankan lokal

Buka `index.html` langsung di browser, atau jalankan server statis sederhana:

```bash
python -m http.server 8000
```
